Teaching the LLM the full Qloo API schema for context-accurate cultural discovery.

Instead of hardcoding the same 4 entity categories for every video, ScenePulse by Flownie injects the complete Qloo API specification into the LLM system prompt. When a viewer pauses any video, the LLM inspects the captured frame and 10s audio window, extracts 3 concrete Qloo /search seeds, and dynamically selects the 4 most contextually relevant Qloo /v2/insights URNs.

01 · CONTEXT-AWARE URN FILTERING
For an artisanal espresso pour or Kyoto transit clip, the LLM selects brand, place, destination, and book/movie — automatically excluding unrelated categories like videogame unless gaming or cyberpunk aesthetics are actually present.
02 · MULTI-PROVIDER LLM ROUTING (OPENROUTER / DEEPSEEK READY)
Supports OpenRouter (OPENROUTER_API_KEY for DeepSeek V3/V4 and Vision models) alongside OpenAI-compatible and Gemini endpoints via unified Laravel configuration.
03 · 5-SECOND TIME-BUCKET SQLITE SHIELD
Video timestamps are bucketed to 5-second windows (floor(t / 5) * 5) so public visitors receive instant, verified Qloo responses in under 15ms without exhausting API quotas.
STAGE 01 · CLIENT TELEMETRY

HTML5 <canvas> Frame + 10s Audio Capture

When playback pauses at timestamp T, the browser draws the exact video frame onto an offscreen <canvas> (480×270 Base64 JPEG) and packages it with the trailing 10-second audio spectrum summary.

canvas.toDataURL('image/jpeg', 0.72) + audio_10s_summary
STAGE 02 · SCHEMA-AWARE LLM

Multimodal Extraction & Dynamic URN Planning

The LLM receives the visual frame, 10s audio descriptors, and the full catalog of 9 Qloo entity URNs. It outputs structured JSON containing 3 qloo_seed_queries and 4 qloo_target_requests with causal rationales.

qloo_target_requests: [brand, place, destination, book]
STAGE 03 · LIVE QLOO TASTE AI

Entity Resolution (/search) & Cross-Domain (/v2/insights)

QlooTasteService resolves each seed string to a canonical Qloo UUID via GET /search, then queries GET /v2/insights for each LLM-selected URN using signal.interests.entities.

GET /v2/insights?filter.type=urn:entity:brand&signal.interests.entities=...
STAGE 04 · PRODUCTION CACHE

5-Second Time-Bucket SQLite Persistence

Resolved Qloo UUIDs, affinity scores, and LLM causal hooks are indexed by (video_id, time_bucket). Subsequent requests hit the warm cache in <15ms, while Force Live bypasses cache on demand.

UNIQUE (scene_pulse_video_id, time_bucket) · 5s window
QLOO API SPECIFICATION INJECTED INTO THE LLM SYSTEM PROMPT

Supported Qloo /v2/insights Entity URNs & Contextual Selection Rules

9 SUPPORTED QLOO URNS
Qloo Filter Type URN Domain Key Required Qloo Parameters LLM Scene Selection Rule
urn:entity:brand brand signal.interests.entities Selected when physical products, craft goods, apparel, or lifestyle equipment appear in the frame.
urn:entity:place place signal.interests.entities + filter.location.query Selected for cafes, restaurants, architectural landmarks, or venues (LLM supplies the city such as Seattle, Kyoto, or Nashville).
urn:entity:destination destination signal.interests.entities Selected for travel, transit, regional culture, architecture, or scenic outdoor atmosphere.
urn:entity:book book signal.interests.entities Selected for artisanal craft, intellectual depth, design monographs, culinary guides, or cultural essays.
urn:entity:movie movie signal.interests.entities Selected when cinematic lighting, urban transit, or atmospheric storytelling defines the frame.
urn:entity:artist artist signal.interests.entities Selected when musical instruments, live performance, or distinct rhythmic/acoustic audio is present in the 10s window.
urn:entity:podcast podcast signal.interests.entities Selected for spoken-word, acoustic storytelling, songwriting sessions, or deep-dive documentary scenes.
urn:entity:tv_show tv_show signal.interests.entities Selected for serialized documentary, culinary series, or travelogue aesthetics.
urn:entity:videogame videogame signal.interests.entities Restricted by the LLM prompt: selected ONLY when gaming, esports, sci-fi, or interactive digital visuals are present (never on coffee or acoustic scenes).
